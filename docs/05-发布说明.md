## 二、版本概述

本版本（v1.0.0）为诗词 Web 应用（poetry-app）的 MVP 首次发布版本，实现了诗词浏览、关键词搜索、诗词详情展示、随机推荐四项核心功能，收录来自 chinese-poetry 开源数据集的 314,629 首唐诗宋词，提供古典风格的沉浸式阅读体验。

## 七、已知问题

### BUG-001：ESLint 配置文件缺失

| 项目 | 内容 |
|---|---|
| 缺陷编号 | BUG-001 |
| 描述 | 前后端均缺少 ESLint 配置文件（`.eslintrc.*` 或 `eslint.config.*`），导致 `npm run lint` 命令无法执行 |
| 严重度 | **低** — 不影响应用功能，仅影响代码规范检查流程 |
| 影响范围 | AC8 验收标准无法通过自动化验证 |
| 临时规避 | 手动检查代码风格，遵循 Vue 3 官方风格指南 |
| 修复计划 | 二期补充 ESLint 配置文件 |

### OBS-001：数据为繁体中文，简体搜索受限

| 项目 | 内容 |
|---|---|
| 编号 | OBS-001 |
| 描述 | 数据库中的诗词数据以繁体中文存储（如"春風"而非"春风"，"故鄉"而非"故乡"），使用简体关键词搜索时无法匹配到对应内容 |
| 严重度 | **低** — 属于数据特征而非功能缺陷，搜索功能本身正确 |
| 影响范围 | 简体用户需使用繁体关键词才能搜索到匹配结果 |
| 临时规避 | 使用繁体中文关键词进行搜索 |
| 修复计划 | 二期考虑增加繁简转换功能（对应 REQ-008） |

## 八、安装与启动

### 8.1 环境要求

| 环境 | 最低版本 | 推荐版本 | 说明 |
|---|---|---|---|
| Node.js | >= 18.0.0 | 18 LTS 或 20 LTS | 前后端运行时 |
| npm | >= 8.0.0 | >= 9.0.0 | 随 Node.js 附带 |
| Git | >= 2.20 | 最新版 | 用于克隆 chinese-poetry 数据集 |
| 操作系统 | — | — | macOS / Linux / Windows 均可 |
| 磁盘空间 | >= 500 MB | >= 1 GB | 数据集 ~200MB + 数据库 ~304MB + node_modules |
| 内存 | >= 2 GB | >= 4 GB | 数据导入时峰值内存约 500MB |

### 8.2 安装步骤

```bash
# 1. 克隆项目仓库
git clone <project-repo-url> poetry-app
cd poetry-app

# 2. 安装前后端所有依赖
npm run install:all
# 该命令依次安装 src/server 和 src/client 的依赖
# 也可分别安装：
# cd src/server && npm install
# cd ../client && npm install
```

### 8.3 数据初始化

```bash
# 一键下载数据集并导入 SQLite
npm run init-data
# 首次执行会自动 git clone chinese-poetry 数据集（约 200MB）
# 然后执行 ETL 脚本：读取 JSON -> 字段映射 -> 过滤去重 -> 批量导入 SQLite
# 预计耗时 1-2 分钟
# 导入完成后输出统计报告（诗词数、作者数、朝代数）
```

### 8.4 启动命令

```bash
# 开发模式启动（前后端同时启动）
npm run dev
# 前端开发服务器：http://localhost:5173
# 后端 API 服务：http://localhost:3000
```

### 8.5 访问地址

| 服务 | 地址 | 说明 |
|---|---|---|
| 前端（开发） | http://localhost:5173 | Vue 3 SPA，Vite 开发服务器 |
| 后端 API | http://localhost:3000 | Express REST API |
| 前端首页 | http://localhost:5173/ | 随机推荐 + 快捷入口 |
| 浏览页 | http://localhost:5173/browse | 诗词分类浏览 |
| 搜索页 | http://localhost:5173/search?q=关键词 | 搜索结果 |
| 详情页 | http://localhost:5173/poem/:id | 诗词详情 |

## 十、回滚方案

MVP 阶段为本地运行，回滚方案如下：

### 10.1 回滚步骤

```bash
# 1. 停止服务（Ctrl+C 终止 npm run dev 进程）

# 2. 删除数据目录（含数据库文件和数据集）
rm -rf data/

# 3. 删除依赖目录
rm -rf src/server/node_modules/
rm -rf src/client/node_modules/

# 4. 重新安装与初始化
npm run install:all
npm run init-data
npm run dev
```

### 10.2 回滚说明

| 项目 | 说明 |
|---|---|
| 回滚范围 | 删除 data/ 和 node_modules/ 后重新安装 |
| 数据恢复 | 重新执行 `npm run init-data` 即可重建数据库 |
| 代码回滚 | 使用 `git checkout` 切换到目标版本 |
| 预计耗时 | 重新安装 + 数据初始化约 3-5 分钟 |
