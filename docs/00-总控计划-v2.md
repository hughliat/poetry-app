## 二、二期范围决策（好用易用原则）

### 2.1 二期做什么

| 编号 | 功能 | 优先级 | 决策理由 |
|---|---|---|---|
| F5 | 繁简切换 UI | P0 | 后端已有 opencc-js 转换能力，前端加切换按钮即可，用户最直接感知的体验提升 |
| F6 | 搜索体验优化 | P0 | 修复一期遗留高亮问题（originalKeyword 未使用），优化搜索结果展示 |
| F7 | 移动端适配 | P0 | 一期仅适配桌面/平板，手机是最常见使用场景，必须覆盖 |
| F8 | 诗词收藏（localStorage） | P1 | 无需注册登录，一键收藏+收藏列表，最轻量的个性化功能 |
| F9 | 自动化测试 | P1 | 一期遗留改进项，保证迭代质量，Vitest + Supertest 覆盖 7 个 API |

### 2.2 二期不做什么（三期考虑）

| 排除项 | 原因 |
|---|---|
| AI 诗词赏析与配图 | 需外部 AI API，成本和可用性不确定，非"好用易用"核心 |
| 社区互动（评论/分享/讨论） | 功能过重，需用户系统前置，与"轻量"定位冲突 |
| 公网部署 | 基础设施投入，不影响本地使用体验 |
| 用户注册/登录系统 | localStorage 收藏已满足核心需求，无需引入账号体系 |
