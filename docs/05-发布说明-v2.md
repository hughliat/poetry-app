## 二、版本概述

本版本（v2.0.0）为诗词 Web 应用（poetry-app）的二期发布版本。在一期 MVP（v1.0.0）的基础上，新增繁简切换 UI、搜索体验优化、移动端适配、诗词收藏四项新功能，并引入 Vitest + Supertest 自动化测试框架（35 个测试用例覆盖全部 7 个 API）。同时修复了一期遗留的 BUG-001（前端高亮未使用 originalKeyword）和二期测试中发现的 BUG-002（测试代码 URL 编码），优化了数据库路径（OBS-002）。所有二期验收标准（AC9-AC14）均已通过。

## 八、启动命令变更

### v1.0.0 启动方式（已废弃）

```bash
# 直接通过 app.js 启动后端
npm run dev:server
# 或生产模式
npm start
```

### v2.0.0 启动方式

```bash
# 开发模式（不变）
npm run dev

# 后端启动改用 start.js（v2.0.0 变更）
node src/server/start.js
# start.js 导入 app.js 导出的 Express 应用，调用 app.listen() 启动服务
# app.js 不再直接调用 listen，便于测试导入

# 运行自动化测试（v2.0.0 新增）
npm test
# 等价于 cd src/server && npx vitest run
```

### 命令变更说明

| 命令 | v1.0.0 | v2.0.0 | 说明 |
|---|---|---|---|
| `npm run dev` | 前后端同时启动 | 不变 | — |
| `npm run dev:server` | `node src/server/app.js` | `node src/server/start.js` | 启动入口改为 start.js |
| `npm start` | `node src/server/app.js` | `node src/server/start.js` | 同上 |
| `npm test` | 无 | `cd src/server && npx vitest run` | **v2.0.0 新增** |

## 十一、回滚方案


| 项目 | 说明 |
|---|---|
