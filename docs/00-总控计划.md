#### 待改进

1. **opencc-js API 使用错误**
   - **问题**：小开首次使用 `OpenCC.Converter('simplified', 'traditional')` 错误调用，导致服务启动失败
   - **根因**：未查阅官方文档，凭猜测使用 API
   - **改进**：引入新依赖时，必须先查阅官方文档或 README，确认正确用法
   - **后续行动**：小开在开发设计中补充"依赖引入规范"章节

2. **数据库路径定位问题**
   - **问题**：`database.js` 使用 `../../../../data/poetry.db`（向上 4 级）定位数据库，路径较脆弱
   - **根因**：项目实际目录结构与开发设计预期不完全一致
   - **改进**：使用环境变量 `POETRY_DB_PATH` 或 `process.cwd()` 动态计算路径
   - **后续行动**：已在运维手册中说明环境变量配置方式

3. **端到端测试缺失**
   - **问题**：MVP 阶段采用手动测试 + curl，未编写自动化测试用例
   - **根因**：时间优先，先保证功能可用
   - **改进**：二期补充 Vitest + Supertest 自动化测试，覆盖 7 个 API 的正常与异常场景
   - **后续行动**：记录为二期 P1 需求

4. **前端高亮未适配 originalKeyword**
   - **问题**：后端返回 `originalKeyword` 字段，但前端未使用，高亮仍用请求参数
   - **根因**：繁简转换功能修复时未同步更新前端
   - **改进**：前端搜索页应优先使用后端返回的 `originalKeyword` 进行高亮
   - **后续行动**：二期优化
